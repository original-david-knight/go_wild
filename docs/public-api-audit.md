# Public API Audit — Baseline

Baseline snapshot of each library's subpackage usage across workspace modules.
Generated by `scripts/public-imports.sh` on 2026-04-18 against every library
listed in the root `go.work`.

This captures the starting point before the per-library `internal/` sweep
(TODO.md "Hide internals" section). For each subpackage of a library, the
script lists every workspace package outside the module that imports it. A
subpackage with zero external importers is a candidate for `internal/`.

## How to reproduce

```bash
# single module
scripts/public-imports.sh my

# full baseline (one module per block)
for mod in my data tools knowledge_graph deep_research polymarket crypto \
           agentic_loop codexllm claudellm agent_data agent_node agent_net \
           objectives; do
  echo "===== $mod ====="
  scripts/public-imports.sh "$mod"
done
```
